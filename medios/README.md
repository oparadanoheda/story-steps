# Medios

- `img/<unidad>/` — imágenes en WebP (flashcards, páginas de cuento, dibujos para casa).
- `audio/<unidad>/` — audio en Opus o MP3 mono comprimido (palabras, cuento, chant, audio diario).

Los originales de alta resolución y los vídeos no se guardan aquí: el sitio publicado no puede pasar de 1 GB.
Cada recurso de terceros se anota en `../creditos/atribuciones.csv` en el mismo commit en que se añade.
