# Interactivos

Motores reutilizables para la pizarra digital que se alimentan de los datos de cada unidad (`contenido/`).

Previstos: cuento digital, rutina del día, agenda visual, Listen and point/touch, What's missing?, Pair game, Bingo caller, ruleta o dado, Who says…?
El piloto empieza por estos tres: cuento digital, Listen and touch y bingo.

Requisitos (ver `CLAUDE.md`): JavaScript sin dependencias, exportable como un único HTML sin conexión, modos táctil y sin táctil, botones de al menos 80 px y nada que dependa de leer.
